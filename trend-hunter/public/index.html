Claves y proxy

Todo se guarda solo en este navegador (localStorage) y las llamadas van directo desde tu dispositivo — nunca pasan por ningún servidor nuestro.

¿No tienes clave de YouTube? Sácala gratis en la Google Cloud Console (esta sí es obligatoria). El proxy propio es opcional, solo para cuando el público falle mucho — instrucciones en trend-hunter/worker/README.md (5 min, gratis, sin tarjeta).
