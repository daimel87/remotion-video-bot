🎬 Pipeline audio → video

1Audio → SRT (Whisper local)

Necesita whisper instalado, o pon un SRT en el campo de arriba.

2SRT → tomas + queries

Rellena por toma una query visual concreta en inglés (2-4, separadas por coma). Claude también puede rellenarlas por ti.

3Descargar candidatos (Pexels + Pixabay)

✓Elegir el clip que ilustra cada frase

Corre el paso 3 para ver los candidatos aquí.

4Generar cues + render

Luego, en terminal: npx remotion render AutoStockEdit renders/<nombre>.mp4
