# incoming/ — archivos crudos para montar videos

Sube aquí los clips de Pexels y el audio (ElevenLabs) desde la app de GitHub.
Claude los mueve a `public/` y monta el video.

- `incoming/komodo/` — clips + audio del video del dragón de Komodo.

Nota: GitHub limita la subida web/app a **25 MB por archivo**. Si un clip pesa
más, descárgalo de Pexels en una resolución más baja (HD/SD) antes de subirlo.
