# Catálogo completo de formatos de miniatura

Extraído frame por frame de las 27 capturas subidas (galería de plantillas de
una app de miniaturas). Cubre cualquier nicho, no solo historia/objetos —
organizado por categoría de contenido para que un detector automático pueda
navegar por grupo antes de elegir el formato específico.

## 1. Reacción / rostro a cámara
| Formato | Descripción visual |
|---|---|
| Review Reaction | Rostro con expresión exagerada + objeto/producto que se está reseñando |
| Commentary Reaction | Rostro reaccionando en primer plano sobre un clip de fondo |
| Broadcast Reaction | Rostro celebrando/gritando sobre transmisión deportiva de fondo |
| React Feed | Rostro + feed de chat/redes sociales superpuesto |
| Reaction Trio | Tres rostros en fila reaccionando al mismo estímulo |
| Science Reaction | Rostro sorprendido junto a imagen/objeto científico |
| Year Reaction | Dos rostros comparando reacciones "año pasado vs. este año" |
| Chat Hook | Captura de chat/mensaje + rostro señalando con flecha dibujada a mano |

## 2. Retrato / cita
| Formato | Descripción visual |
|---|---|
| Retrato Grabado (Engraved Portrait) | Foto vintage en B&N o textura de placa, headline bold arriba |
| Retrato con Cita (Portrait Quote) | Retrato dramático en B&N/duotono, cita en tipografía serif elegante |
| Editorial Portrait | Retrato estilo revista/editorial con una sola palabra grande |
| Mono Portraits | Varios retratos en escala de grises alineados |
| Accent Portrait | Retrato con un color de acento único resaltando parte de la imagen |
| Mood Quote | Retrato + cita corta motivacional/reflexiva |
| Throwback Quote | Foto de archivo antigua + cita superpuesta |
| Inset Quote | Foto principal + recuadro pequeño con cita |
| Solo Quote | Una sola persona + cita textual grande |
| Bold Statement | Rostro + afirmación contundente en texto masivo |
| Flag Figure / Flag Name / Flag Interview | Persona + bandera de país de fondo, nombre o cita grande |
| Split Face | Rostro partido a la mitad (dos versiones/etapas) |
| Face Merge | Dos rostros fusionados/superpuestos con transición |

## 3. Objeto / producto
| Formato | Descripción visual |
|---|---|
| Evidencia en Mano (Evidence Hold) | Mano sosteniendo el objeto real, dato/cifra flotando al lado |
| Estudio de Objeto (Object Study) | El objeto solo, fotografía limpia, caption corto en itálica |
| Objeto Concepto (Concept Object) | El objeto renderizado dramáticamente, fondo oscuro, un foco |
| Objeto Elevado (Pedestal Reveal) | El objeto sobre un pedestal, iluminado como trofeo |
| Objeto Surreal (Surreal Object) | Versión distorsionada/fuera de contexto de un objeto cotidiano |
| Product Hero | El producto como protagonista único, fondo neutro |
| Product Reveal | El producto "revelándose" (mano abriendo caja, cortina, etc.) |
| Product Arrow | Flecha señalando el producto desde una persona |
| Overhead Hold | Objeto sostenido en alto sobre la cabeza |
| Prize Rig | Premio/producto rodeado de elementos de "trampa" o suspenso |
| Prize Reveal | Persona mostrando el premio recién ganado/revelado |
| Sign Hold | Persona sosteniendo un letrero/cartel con texto escrito a mano |
| Hand Phone | Mano sosteniendo un teléfono con la pantalla visible |

## Cómo se usa en el flujo de Opal

Un paso nuevo (Paso 1.5) recibe el gancho extraído y elige, dentro de estas
13 categorías y sus formatos específicos, el que mejor encaje con lo que la
transcripción realmente describe — funciona para cualquier nicho, no solo
para historia de objetos/marcas.
