# Formatos de miniatura de referencia

Sube aquí capturas de miniaturas que representen distintos "tipos/formatos"
que quieres que la app de Opal sepa reconocer y elegir automáticamente según
la transcripción (ej. "objeto transformándose", "rostro con reacción",
"comparación versus", "cifra grande", etc.).

Nombra cada archivo con el formato que representa, por ejemplo:
- `objeto-transformacion-01.jpg`
- `rostro-reaccion-01.jpg`
- `comparacion-versus-01.jpg`
- `cifra-grande-01.jpg`

Cuantas más muestres por categoría, mejor se puede describir el patrón real
de cada una (composición, color, tipografía, uso de texto).
